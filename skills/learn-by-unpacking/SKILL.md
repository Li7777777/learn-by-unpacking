# 图文并茂教程生成器

将一个技术主题或代码库转化为可持续学习的三件套：教程、伴读导师提示词、学习记录模板。默认使用简体中文，保持循循善诱、层层追问、解释设计取舍的导师风格。

## 何时启用

启用条件包括：

- 用户要求生成图文并茂的技术教程或学习系统。
- 用户提到“反推提示词”“伴读学习”“源码精读”“学习记录”“教程 + 检验 + 复习”。
- 用户希望从整个项目或代码库生成源码教程。

如果用户只是询问一个普通技术问题，不要启用本 skill。

## 核心约束

1. 在开始产出任何文件前，必须询问并确认：学习主题、阅读模式、源码范围（如适用）、学习天数和每日可用时长。

2. 必须先规划章节，再估算学习时长和推荐天数。推荐公式为：
   
   ```text
   推荐天数 = ceil(全部章节总阅读时长 / 每日可用时长)
   ```
   
   默认每日可用时长为 150~180 分钟。完成正文章节后额外安排一个不计入公式的全量复习日。

3. 源码精读模式下，教程正文只能在覆盖率达到 100% 后开始。必须逐文件、逐段读到文件末尾，记录真实行号、依赖、调用链、错误分支、配置、测试和示例。

4. 不编造事实、命令、数字、版本或行号。无法核实的内容明确标记“待核实”。

5. 交付的三个文件必须互相引用，章节数量、天数分配、文件名和路径保持一致。

6. 单章至少使用四种图文手段：ASCII 图、SVG 配图、对比表、代码块、引用 blockquote、加粗标记中的任意四种。配图必须解释结构或流程，不得只是装饰。

7. 每一章都回答“是什么、怎么做、为什么”，并说明设计取舍、易混概念和可迁移方法。

## 工作流程

### 1. 先问，再规划

向用户询问：

- 主题：技术栈、框架、概念或项目。
- 模式：主题讲解，或源码精读。
- 源码精读时：项目路径或仓库地址、阅读范围；默认读取全部源码和关键配置，排除第三方依赖、构建产物、锁文件等生成物，并说明排除理由。
- 每日可用时长和目标学习天数。

先做章节规划，估算每章 15~40 分钟，优先将核心章节和有依赖的章节安排在前面。向用户展示推荐天数、公式、总阅读时长、每日分配和额外复习日，然后再等待确认或开始生成。

### 2. 准备知识或源码

主题讲解模式：确定知识边界，拆成从基础到进阶的章节，标注依赖、难度和核心章节，收集可追溯素材。

源码精读模式：

- 先盘点文件并建立覆盖清单：`文件路径 | 总行数 | 是否读完 | 行号区间 -> 机制`。
- 对范围内每个文件从头读到尾，不抽样、不跳读；必要时分段读取直到最后一行。
- 对每个定义搜索所有调用点，闭合 import/export、入口到最深实现的调用链。
- 保留真实行号。只有确实读到的源码才能在教程中引用。
- 自证格式必须包含：源码文件总数、已读文件数、覆盖率 100%、每个文件的关键行号索引。

### 3. 生成三个交付物

文件 1：`README.md` 或 `教程-<主题>.md`。

每章按以下结构组织：

```markdown
# 第N章：主标题 —— 副标题

> 页面信息：字数 · 代码行数 · 阅读时长
> 开场导读：回顾前章，并加粗本章核心问题。

## 一、引子与直觉
### 1.1 ...

## 二、是什么
## 三、怎么做
## 四、为什么这样设计
## 五、总结与可迁移方法
## 末节：下一站

> **本章关键源码索引**（如适用）
```

教程必须：

- 先类比和直觉，后定义和实现。
- 用“是什么 -> 怎么做 -> 为什么”叙事。
- 展示代码、流程、架构或数据关系，并附图注。
- 对易混概念使用表格或并列小节。
- 主动说明“不做什么”以及这样取舍的原因。
- 章节末总结 1~3 条可迁移方法。

文件 2：`伴读提示词-<主题>.md`。

必须包含：用途说明、角色设定、按天的材料清单、总体学习目标、每天的分章引导流程、中途检查点、当日 7 题考察规则、四类题目库及考察要点、学习记录引导、复习日流程和全程行为准则。提示词主体用明确的开始/结束标记包裹，便于复制给另一个 AI。

伴读流程：导读 -> 学员阅读 -> 结构化讲解 -> 开放式追问；先听学员回答再点评，不一次性灌输。每日考察固定为概念 2 题、源码 2 题、设计 2 题、综合 1 题，每题 0~10 分。掌握画像为：绿色 >=8，黄色 5~7，红色 <=3，并指向需要回看的章节。

文件 3：`学习记录-<主题>.md`。

必须包含：天数概览、每日计划表、核心知识点压缩笔记、自测成绩表、疑问清单、错题复盘、至少三条收获、串联图/口头串讲留白，以及复习日目标、计划、记忆锚点、重考成绩和结课清单。

### 4. 交付前自检

逐项核对：

- 已确认主题、模式、天数和每日时长，并展示公式。
- 教程每章含元信息、导读、至少四种图文手段、总结和下一站。
- 每章都有类比、设计取舍、易混对照和可迁移方法。
- 伴读提示词包含四类题库、评分、掌握画像和复习日。
- 学习记录模板覆盖每日与复习日全部字段。
- 三个文件的章节、天数、路径一致。
- 源码模式有 100% 覆盖清单，所有引用行号真实可查。
